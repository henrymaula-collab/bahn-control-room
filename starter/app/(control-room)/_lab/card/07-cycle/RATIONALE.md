# card 07: Options in place

- Reference: Superhuman Instant Reply (https://help.superhuman.com/hc/en-us/articles/46005583725709-Instant-Reply, `research/premium/product/shots/card-06-superhuman-instant-reply.png`): three drafted replies at the foot of the message; Tab cycles and previews each where the reply will go, Enter takes the one shown.
- Borrowed: Other options as a cycle instead of a sheet. One line names whose answer is shown ("The agent suggests" / "Instead of the suggestion") with "1 of 2" and two arrows (and the arrow keys); the question, its button and its next line swap together, so each option is read in the same place and the same words as the default.
- Why for ops: comparing two answers is the real work on a hard case; seeing the alternative's own consequence ("Nothing is sent") in place beats a list of labels in a sheet.
- The suggestion stays the filled button; an alternative's button is the quieter secondary and still asks why (the sheet, reason step), so the learning loop keeps its reason.
- Trade-off: only one option is visible at a time; Tab is left to focus, so the cycle is on arrows rather than Superhuman's Tab.

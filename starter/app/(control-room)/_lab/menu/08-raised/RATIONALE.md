# menu 08: The open section raised, like Arc

References: Arc browser's sidebar, where the open tab is a raised white row on the tinted sidebar (https://arc.net; the site now shows only Arc's farewell page, `research/premium/visual/shots/menu-mm-arc-farewell.png`, so no shot of the sidebar was reachable); Apple HIG Segmented controls, the same idea in Apple's own controls: the selected segment is a raised light thumb on a tinted track (https://developer.apple.com/design/human-interface-guidelines/segmented-controls, `research/premium/visual/shots/menu-mm-hig-segmented.png`).

Borrowed: selection as material, not colour: the open row is a birch surface with a hairline ring and a soft shadow on the grey-50 frame; hover is a half-raised tint.

Why it helps: the open row is the same white as the page card beside it, so the menu row and the page read as one object (this row is that page). It is calmer than a fill, keeps the menu quiet for the video, and needs no new colour.

Trade-off: the difference between selected and hover is subtle on a dim screen; Arc itself is being retired, so the reference is a pattern, not a product to point at.

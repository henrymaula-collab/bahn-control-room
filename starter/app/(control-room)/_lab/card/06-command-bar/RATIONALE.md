# card 06: Command bar

- Reference: Raycast's action panel (https://developers.raycast.com/api-reference/user-interface/action-panel, https://manual.raycast.com/action-panel; raw `research/premium/product/raw/pp/raycast-actionpanel.md`): the first action on Return, Cmd+K lists every action with its key on the right. Key glyphs inside the buttons as Claude in Chrome's plan approval shows them (`research/premium/product/shots/chat-05-claude-chrome-plan-approval.png`).
- Borrowed: Cmd+Return for the default answer and Cmd+K for one list of every action (the suggestion, each alternative with its effect in one grey line, then Talk it through and the situation), arrow keys and Return inside the list, the keys written quietly in the buttons.
- Why for ops: an expert who decides dozens of cases a shift never reaches for the mouse, and the list shows every way out with its consequence before the sheet asks why.
- Keys follow Primer and HIG: a modifier on every shortcut (no single letters), Escape closes, every key has a visible button.
- Trade-off: key hints are noise for a newcomer and mean nothing on a touch screen; picking an alternative still opens the sheet for the reason.
